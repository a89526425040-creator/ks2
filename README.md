# KS2

Windows tactical first-person shooter prototype built with Godot 4.4.1.

## Current playable foundation
- First-person movement and mouse look
- 5v5 match setup: player + four friendly bots against five enemy bots
- Compact industrial training arena with cover
- Three weapon slots: rifle, pistol and sniper
- Ammo, reload, health, round timer and bomb-site marker
- Basic bot combat AI
- Windows export through GitHub Actions

## Controls
- WASD — move
- Mouse — aim
- Left mouse — fire
- R — reload
- 1 / 2 / 3 — weapon slots
- Shift — sprint
- Space — jump
- E — interact
- Esc — release/capture mouse

The project is an early playable foundation. Bot navigation, bomb planting/defusing flow, animations, sound, menus, progression and visual polish remain to be expanded.
